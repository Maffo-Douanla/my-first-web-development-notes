what is a client
A client is a computer that requests information or services from a server e.g My laptop is a client and i use my browser to communicate with the server
What is a server?
a server is a computer or system that provides services or information and also stores information e.g Github server
How do clients and server communicate?
the client sends a request and the server sends back a response. they follow network protocols like HTTPS which is very secure
